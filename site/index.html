Why Tungsten exists

Private browsers should not make the web feel worse.

Too many privacy-first browsers ask for a compromise: slower pages, broken apps, unfamiliar UI, or a pile of extensions you are supposed to trust.

Chrome is compatible, but it is not built around native Mac conventions or user-first privacy. Tungsten takes a different route: keep the web working, keep the app Mac-native, and make privacy modes clear.

Core directives

Four requirements for a browser people can actually use.

01

Put privacy in the browser

Content blocking and privacy modes should be part of the product, not a chain of third-party extensions you have to vet and trust.

Keep the modern web working

Compatibility matters. A private browser that breaks the daily sites people use for work, banking, and media becomes shelfware.

Feel at home on macOS

  • Native menus & shortcuts
  • Real window behavior
  • macOS-native packaging

Separate privacy modes clearly

Normal, private, and Tor tabs should be obvious choices, not hidden states buried in a menu.

How it differs

A private browser without the usual penalty.

Less extension trust

Plugins can help, but every one adds another party to trust. Tungsten keeps core privacy behavior inside the app.

Fewer compatibility surprises

A private browser still has to open the sites people use for work, banking, media, and daily life.

More Mac-native by default

A browser people keep open all day should behave like a Mac app, not like a web app in a desktop frame.
